# PostgreSQL

Esta pasta contém os arquivos relacionados à implementação do benchmark TPC-H no PostgreSQL.

## Conteúdo esperado

- Scripts de criação do banco
- Scripts de importação dos dados
- Consultas SQL executadas
- Configurações utilizadas nos testes
- Evidências e resultados obtidos

## Objetivo

Executar as consultas do benchmark TPC-H utilizando o modelo relacional e registrar os tempos de execução para comparação com o MongoDB.
